## v0.8.0: Prompts, saved text you can drop into a roleplay

### 📜 Prompts
A new **Prompts** item in the side bar opens as a drop-down, so you never leave your roleplay.
- **Drag a prompt into the chat** (press and hold, then drop it on the chat) and it is sent as your message at once.
- **If you've already typed something,** the prompt is added to your message box instead, so you can add to it and send it yourself. Nothing goes out by surprise.
- **Click a prompt** to put it in the message box. That's also how it works on a phone, where dragging isn't available.
- **＋ New prompt** to add one (a title, an optional label, and the text). Edit, copy and delete from the same drop-down.

Prompts are per profile and are included in profile backups.

### Notes
- Tested with prompts made for the tests, dragging with a mouse. Please tell me if dragging feels off on your setup.
