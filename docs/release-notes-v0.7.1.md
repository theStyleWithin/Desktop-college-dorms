## v0.7.1: bigger chat text

### 🔠 Text size slider
Make the text in your roleplays bigger (or smaller): from 80% to 200%.
- **In the chat itself:** a small slider next to the other chat options, so you can adjust it while you read.
- **In Settings → Appearance:** the same slider with a sample, and a Reset button.

It changes the messages, the message editor, the box you type in, and the texting-style bubbles. The rest of the app stays the same size. The setting is kept on each device, so a phone and a computer can have different sizes.
